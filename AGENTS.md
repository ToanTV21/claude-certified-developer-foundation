# AGENTS.md — Claude Certified Developer, Foundations Study Project

Toàn bộ context, quy ước, và AI behavior rules của project này được định nghĩa trong
[`CLAUDE.md`](./CLAUDE.md) ở root — file này chỉ là pointer để các agent/tool khác
(không đọc `CLAUDE.md` mặc định) vẫn nạp được đúng context.

**→ Đọc `CLAUDE.md` trước khi làm bất kỳ việc gì trong repo này.** Mọi rule (directory
layout, domain blueprint, coding conventions, note-taking template, exercise template,
git commit/push rule, ngôn ngữ chat vs ngôn ngữ ghi note...) đều nằm ở đó, không lặp lại
ở đây để tránh 2 file lệch nhau theo thời gian.

Nếu `CLAUDE.md` thay đổi, coi như AGENTS.md tự động cập nhật theo — không cần sửa file này
trừ khi cần thêm hướng dẫn riêng cho agent không hiểu `CLAUDE.md`.
